# FFT Portfolio

## Project Overview

FFT Portfolio is a front-end portfolio website created to present projects, technical skills, learning experiences, and professional information in one place.

## Purpose

The project focuses on building a clear and responsive personal portfolio using modern front-end practices. It provides a central way to showcase work such as data science, machine learning, generative AI, backend, and web-development projects.

## Highlights

- Personal project presentation.
- Responsive portfolio layout.
- Structured sections for skills and experience.
- Front-end practice using reusable web assets.
